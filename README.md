# 风经过

一款以亲近自然为主题的全屏互动小工具。指尖划过植物，枝叶或草穗随风摆动，少量花叶飘落并逐渐恢复。支持梧桐、银杏、樱花、垂柳、蓝花楹、粉黛乱子草和细叶针茅，以及白天、雨天、月夜三个场景。右上切换场景，底部选择植物；声音、轻吹、重置收在左下工具入口，右下可进入沉浸模式。

树体在静止时缓存，雨丝、萤火虫与树体分层更新；两种草和手机端的柳叶、樱花采用 WebGL 图集批量绘制，并提供 Canvas 兼容回退。雨天远景、月夜光带以跨浏览器的缓存柔化图层绘制，避免 iOS Canvas 滤镜差异。声音由 Web Audio 合成，不包含 MP3 等音频文件。

运行网页版：`python3 -m http.server 8765 --directory dist`，然后打开 `http://localhost:8765`。页面无需构建；声音通过 Web Audio 生成，浏览器可能要求首次触摸后才能播放。

运行测试：`node --test tests/*.test.js`。测试覆盖风场、枝叶运动、飘落与再生、减少动态偏好和音频控制。自动化浏览器检查不能代替 iOS、Android 真机的触控、声音和性能验收。

`branding/` 中保存图标方案；当前简约版为 `风经过-简约图标-512.png`。美术素材中，一部分叶片来自用户提供的参考素材，其余植物纹理由 imagegen 生成；用于公开发布时，请另行确认第三方参考素材的使用权。

雨天场景版：移除四季与昼夜组合入口，默认呈现阴天庭院、保留原始黄橙色层次、略微偏冷压暗的枝叶、远近三层雨丝、潮湿地面与浅水涟漪。落雨、落点和背景按屏幕尺寸绘制，微风带动树冠轻摆。叶尖水珠互动暂不启用。保留六种植物、轻吹、重置和原有风声开关；本轮尚未加入专门的雨声音轨。减少动态模式冻结降雨、涟漪与背景摆动。

右上角图标按钮切换白天／雨天，切换保留所选植物与当前枝叶状态。页面不显示标题和说明文字。

水面更新：涟漪采用延迟扩散的多重明暗弧线，只在水坑内绘制。雨天水坑映出当前植物的一小部分，倒影按树根位置翻转、压缩并逐行轻微扰动，随距离淡出；减少动态模式固定倒影，不播放波纹。

当前雨景已撤下大水坑、倒影与水面涟漪，保留湿地和落雨溅点。新增少量叶缘水珠，沿真实图片轮廓挂水，逐渐积大，触碰或积满时落下并重新积水；白天不显示水珠，减少动态模式不播放滴落动画。

水珠优化：降低数量与尺寸，弱化蓝色填充和完整白色描边。先出现叶缘湿润反光，再长出透明小水珠，接近脱落时短暂拉长；附着点固定在叶片纹理上，避免随旋转跳点。

落雨更新：雨滴落在湿地时出现两层细小椭圆波纹，随距离调整大小，约一秒内扩散淡出；不恢复大水坑或倒影。

控制区使用透明背景，无磨砂、共享胶囊或选中小卡片。植物选择保留小下划线；桌面底部控件共用基线，手机植物切换独立上排，短横屏改为底部一排。`qa/layout-check.mjs` 覆盖桌面、手机、小屏、横屏和断点附近的锚点、留白与按钮交互。

湿叶更新：雨天部分前景叶片叠加按纹理透明区域裁切的柔和反光，保持叶色。雨粒经过采样叶面时触发短暂亮面和衰减轻颤，同一雨粒只触发一次；减少动态模式不触发碰撞动画，白天不显示湿反光。

雪天场景：天气按钮按雨天→雪天→白天循环。雪天呈现冷灰蓝远景、浅雪地面及前后两层缓慢飘雪，保持原始植物色彩；少量叶片上缘覆雪，划动或轻吹可抖落，随后缓慢重新积雪。减少动态模式保留静态雪景与覆雪，关闭飘雪及散落动画。

梧桐冬景试版：雪天的梧桐显示裸枝和极少量残叶，积雪改为沿枝杈上缘分布；划动可抖落枝雪，缓慢重新积回。仅改变雪天渲染，不修改原植物模拟或白天、雨天的叶量。访问 `/?winter=maple` 可直接进入梧桐雪景，其他植物尚未制作对应的冬季形态。

当前版本已撤下雪天及梧桐冬景试版，天气按钮只切换白天／雨天。旧 winter 查询参数不再启用雪景。

雨打落叶增强：少量成熟叶片被实际雨粒命中后先下压轻颤，延迟松动再飘落，给脱落初段少量向下与侧向速度。雨致落叶之间至少间隔 2.6 秒，并保留树冠与再生机制。

声音试听版：用原生 Web Audio 在内存中合成 64 秒固定旋律的柔和器乐与 18 秒立体声雨声，替换旧风噪。白天音乐为主，雨天音乐降低并淡入雨声；天气切换保持音乐进度，首次交互后启动，保留静音记忆及后台暂停。发布目录与离线包不包含 MP3、WAV 等音频资源，也无外部音频请求。

枝条演奏试听版：背景改为五声音阶内的稀疏和弦，不播放预设主旋律。手势穿过树木主枝附近时触发稳定映射的音符，粗主枝偏低；单次最多三个候选，音符间距至少 120ms，同枝冷却 700ms，同时最多六个声部。停手不自动奏音，雨打叶片也不奏音。演奏时伴奏压低，停手后平缓恢复；雨声保持独立，粉黛暂不参与枝条演奏。仍为纯代码合成，无音频资源文件。

和声优化：伴奏固定 C 大三和弦，枝条只使用 C/E/G 跨八度音高。快速划动音符至少错开 140ms，短时重复音合并；主要声部最多四个，旧音以短淡出替换，叠加音量随密度降低。保留伴奏退让、雨声与静音机制。

轻柔音色调整：枝条音区收窄为 C4–C5 的 C/E/G 音，移除原 C6 高音；起音约从 8ms 放缓到 32ms，降低高次泛音与回声，并通过 1100Hz 低通柔化高频，高音适当降低音量。保持固定和弦、密度控制与伴奏退让。

Do 音补充：最粗的主枝使用更低的 C3（do），并降低其音量；其余主枝保留 C4/E4/G4/C5，让 do 更容易触发，仍保持同一和弦体系。

垂柳演奏：发声判定覆盖实际下垂细枝，同一主枝下的柳条共用音高和冷却，避免密集柳条触发大量重叠音。

背景伴奏优化：去掉逐音琶音和升八度的高音，改为 C3/G3/C4/E4 同时缓慢进入的柔和和声，12 秒起落包络交叠，清晰的单音交由手势演奏。

月夜试版：场景按钮按雨天→白天→月夜循环。深蓝灰背景、少量静态星点与月亮，植物保留原色但压暗、部分上缘有微弱冷光，背景和声降低，枝条弹奏保持原样。未加入萤火虫。访问 `/?scene=moon` 可直接进入梧桐月夜。

月夜亮度调整：减少叶片统一压暗量，提亮天空与地面，补充淡远景层次。月亮改为较小、近乎均匀的淡白月盘与弱光晕，移除球形明暗和随机斑点。

月夜构图与光照重做：月夜树形缩小下移，增加树冠上方天空留白；月亮与树梢错开。叶片基础暗部和方向性亮面分开绘制，亮边使用反向旋转补偿，使月光方向不随贴图旋转；部分叶片按角度显露柔和高光。本轮不新增拨叶光斑玩法。

拨叶见光：月夜恢复白天同等树形尺寸，撤下可见月盘；划过有叶区域时，局部叶片轻轻向两侧分开，叶面亮度与地面碎光同步增强，松手后逐渐归位和淡出。切换场景、植物及重置均清除光斑，不改变植物模型本身。
